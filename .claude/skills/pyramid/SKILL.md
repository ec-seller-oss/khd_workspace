# 1日1回ピラミッド

**4ヶ月×1日1本で書く力は変わる**（山崎康司）。②の指標はこれ。

## 手順

### 1. OPQを先に立てる（本文より先）
- **O（望ましい状況）**：読み手がすでに知っていて、同意している状態。ここから始める。自分の事情から始めない。
- **P（問題）**：Oが崩れている、または崩れる予兆。
- **Q（読み手の疑問）**：Pを前にして読み手が抱く**1つの**疑問。複数あるなら文章を分ける。
- **A（答え）＝主メッセージ**：Qへの直接の答え。**これを1文目に置く**。

### 2. ピラミッドを組む
主メッセージ（1文）→ 根拠3本 → 各根拠に数字・事実。3本を超えたら削る。

### 3. 4つの鉄則で削る
1. **名詞表現・体言止め禁止**（「収支の改善」→「収支は月4万円改善します」）
2. **あいまい言葉禁止**（「適切に」「しっかり」「検討します」）
3. **1文に1メッセージ**
4. **「しりてが」接続詞禁止**（〜し、〜り、〜て、〜が＝因果をぼかす接続）

### 4. So What? を1回かける
書き終えたら各根拠に「だから何？」と聞く。答えられない根拠は消す。

## Claudeの役割の境界（重要）
- **下書き・構造・削りは全部Claudeがやる。**
- **主メッセージの1文だけは渡さない。** 空欄にして菊池さんに書かせる。ここを代筆すると熱量が消え、②の指標が「Claudeが書いた本数」になって意味を失う。
- 「◯◯（ここを1文で埋めてください）」と明示して返す。

## 出力先と計上
1. `.company/secretary/pyramid/YYYY-MM.md` に**追記**（同月1ファイル、上書き禁止）。日付・O/P/Q/A・本文・宛先。
2. 菊池さんが「送った」と言った時点で計上：
   ```
   python3 scripts/kpi_engine.py log pyramid
   python3 scripts/kpi_engine.py log daseki --who <宛先> --what "<渡したもの>" --kind 提案
   ```
   下書きを作っただけでは②は付かない。**送信が計上条件**。

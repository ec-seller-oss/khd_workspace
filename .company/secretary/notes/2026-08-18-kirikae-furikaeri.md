## 0. 全体の構図（先に1枚）

- **DMN**（ぼーっと／記憶の整理／人の内面を推し量る）と **CEN**（集中／分析／言語・短期記憶）は**正反対の関係＝同時に成立しない**。
- どちらに入るかを切り替えるのが **SN（サリエンス・ネットワーク）**。その入力は**身体・内臓の感覚**。
- したがって課題は「デスク作業と対人の**時間配分**」ではなく、**切り替えの精度**。そして精度は身体で決まる。

> 初日の問い「デスクでAIと決断するのは半分か、0か」は、**問いの立て方そのものが誤り**だった。比率の問題ではなく切り替えの問題。

## 2. モードとロバストネス（動画の骨子 → 自分への適用）

| 動画の言葉 | 自分への翻訳 |
|-----------|------------|
| いろんなモードを用意できるかは、自分の可能性を知ること | モードの**在庫**が資産。1モードしか持たないと変化で折れる |
| やってみたことのないことをやると、一番感情が動く | 未経験の形は**モードの在庫が増える機会**。ただし訳して初めて資産になる |
| ロバストとは変化に強いこと。自分の道を確保しておく | 収入・承認・楽しみの**供給源を複数**持つ＝単一障害点の排除 |
| 誰にも評価されないけれど嬉しいことをいくつも持つ | 趣味ではなく、感情労働を続けるための**装備** |

## 3. AI時代に鍛える側（PIVOT回：平日の仕事の設計）

| 動画の言葉 | 自分への翻訳 |
|-----------|------------|
| 一流は「理解」に手を抜かない／差別化したいなら理解に時間をかける | AIが判断材料を出せる時代、差がつくのは**理解の深さ**と**引き受け**の側 |
| AIはドメイン知識・業務の進め方を自動では生み出せない | 自分の頭の中にあるものは、言語化しない限り資産にならない |
| 最も重要なのは「理解」と「アセット化（資産化）」 | 感情の翻訳＝ミクロのアセット化。業務知の言語化＝マクロのアセット化。**同じ作業** |
| 人間の介入ポイントを設計する | AIに渡すのは**再現可能な判断**。自分が持つのは**引き受けが必要な決断**と**その場に居ること** |

## 4. 運用ルール（これだけ回す）

| 頻度 | やること |
|------|---------|
| 毎日・夜3行 | ①引っかかったこと（事実でなく感じたこと） ②正体（**渡せば消える**／**読めば消える**） ③訳すと何になるか（1行） |
| 毎食前・3秒 | 腹が減っているか一回だけ確認する |
| 会合の翌日 | 「この人はこういう時に動く」と言える人が増えたか、1行で判定 |
| 毎週・日曜 | 今週の予定のうち**自分発は何件**か数える。0なら翌週に最低1件入れる |
| 迷った時 | 入力（勉強・情報）でなく出力（人に会う）を選ぶ |
| 疲れている日 | 反省も設計もしない。行動だけする |

> 3行メモは月曜開始。振り返りを**作る**のは禁止、**回す**だけ。
